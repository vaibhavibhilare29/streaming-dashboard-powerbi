# Streaming Platforms Dashboard (Power BI)

Three Power BI dashboards for **Netflix Originals**, **Amazon Prime** and **Disney+ Hotstar**.

## Problem Statement
Streaming platforms release thousands of titles. This project shows what each catalogue contains: the number of titles, the most common genres and ratings, how releases changed over time, and Movies vs TV Shows.

## Datasets
- Netflix Originals: 584 titles
- Amazon Prime: 9,668 titles (81% movies, 19% series)
- Disney+ Hotstar: 1,450 titles (73% movies, 27% series)

## Key Findings
- Netflix Originals: average IMDb score 6.27 and average runtime 93.58 minutes. Documentary is the most common genre.
- Amazon Prime has the largest catalogue of the three.
- On both Prime and Hotstar, movies are the majority.

## Limitations
- The Netflix file has no Movie/TV Show column.
- Netflix uses IMDb scores, while Prime and Hotstar use age ratings, so ratings are not compared.
